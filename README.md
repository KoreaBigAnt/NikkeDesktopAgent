# NIKKE Desktop Agent

니케 캐릭터를 Windows 바탕화면 위에 띄우는 데스크톱 펫입니다. Gemini로 일상 대화를 하거나 Codex에 작업을 요청할 수 있습니다. 캐릭터는 입력, 응답 대기, 답변에 따라 원본 Spine 모션을 재생합니다.

## 실행

Node.js 22.12 이상이 필요합니다. Electron과 니케 캐릭터를 가져오고 Gemini에서 답변을 받으려면 인터넷 연결이 필요합니다.

```powershell
npm.cmd ci
npm.cmd start
```

기본 대화 방식은 Gemini입니다. [Google AI Studio](https://aistudio.google.com/api-keys)에서 키를 발급한 뒤 펫을 우클릭하고 **Gemini 키**를 선택하세요. 키를 입력하고 **키 저장**을 누르면 연결을 확인하고 이 PC에 암호화해 저장합니다. Gemini 대화에는 Google 프로젝트의 API 한도가 적용됩니다.

Codex 작업을 하려면 우클릭 메뉴의 **대화 방식**에서 **Codex 작업**을 선택하세요. Codex 실행 파일을 찾지 못하면 `$env:NIKKE_CODEX_PATH`에 `codex.exe`의 경로를 지정하세요. 작업 폴더는 앱을 시작한 폴더입니다. 다른 프로젝트에서 사용할 경우 실행 전에 `$env:NIKKE_WORKSPACE`에 그 폴더의 절대 경로를 지정할 수 있습니다.

## 조작

- 캐릭터나 입력창을 우클릭하면 캐릭터 선택, 대화 보기, 항상 위에 표시, 최소화, 닫기 메뉴가 열립니다. 처음 실행하면 라피가 표시됩니다.
- **페르소나 설정**에서 성격과 시스템 프롬프트를 저장할 수 있습니다. 다음 Gemini 메시지부터 적용됩니다. **테마**에서 채팅 입력창과 말풍선을 블랙 또는 화이트로 바꿀 수 있습니다.
- 캐릭터와 코스튬을 `[ID] 이름`으로 표시합니다. 한국어 이름이 있는 항목은 Nikke-DB의 표기를 사용합니다. 출시순은 오래된 항목부터 정렬하며, 날짜가 확인되지 않은 항목은 마지막에 표시합니다. 출시일은 [GachaPortal 캐릭터 목록](https://gachaportal.com/nikke/characters/)과 [NPC JAIL 출시 기록](https://npc-jail.pages.dev/data/nikke/timeline.json)을 기준으로 합니다.
- 캐릭터를 짧게 클릭하면 원본 터치 모션이 재생됩니다. 캐릭터를 끌어서 이동하고, 캐릭터 위에서 휠을 위로 돌려 키우거나 아래로 돌려 줄일 수 있습니다. 투명한 여백은 뒤에 있는 창을 클릭할 수 있습니다.
- 입력창에서 `Enter`로 전송하고 `Shift+Enter`로 줄바꿈합니다. 대화는 `Esc` 또는 대화창의 닫기 버튼으로 접을 수 있습니다. 작업 중에는 중지 버튼이 표시됩니다.
- 앱을 열거나 캐릭터를 바꾸면 선 자세로 시작합니다. 글을 쓰면 정면으로 앉고, 전송하면 돌아앉아 답변이 올 때까지 사격합니다. 답변은 다시 정면으로 앉은 자세에서 표시합니다. 앉은 캐릭터를 클릭하면 원본 재장전 모션을 재생합니다. 캐릭터 클릭이나 채팅이 1분간 없으면 다시 일어섭니다. 답변이 끝나고 8초가 지나면 말풍선이 접힙니다. 우클릭 메뉴의 대화 보기에서 다시 열 수 있습니다. 모션이 없는 캐릭터는 불러올 수 있는 자세를 사용합니다.
- 펫에서 보낸 메시지는 실행 중 선택한 서비스의 대화로 이어집니다. Codex 작업 모드에서는 같은 작업 폴더의 기존 Codex Desktop 대화도 작업·답변 모션에 반영됩니다.

캐릭터와 애니메이션은 [Nikke-DB 뷰어](https://nikke-db.pages.dev/visualiser)의 공개 리소스를 실행 시 가져옵니다. 펫의 대화 연결에는 [Codex App Server](https://developers.openai.com/codex/app-server)를 사용합니다.
